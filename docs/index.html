      Questions

      Good to know before you start.

      Do I need a build step or a framework?
      No. Add the stylesheet and the script to a page and write HTML. The kit works the same in plain HTML, PHP, Laravel, WordPress or a JavaScript framework.
      Can I change the colours, fonts and corners?
      Yes. Every value is a CSS variable. Use the Create page to choose a look and download a small theme file that you load after the kit.
      How does dark mode work?
      Set data-theme="dark" on the page, or on one part of it. A theme button remembers the choice for each person.
      Do forms still work without JavaScript on the server side?
      Yes. Each form control keeps a normal form field up to date, so a plain form post to PHP receives the values as usual.
      What is the licence?
      The kit's code is under the MIT licence. The heading font, Satoshi, has its own free licence with rules about sharing the font files, so read it before you publish them.
