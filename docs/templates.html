Each template is a single HTML file in the templates folder. Copy the file, fix the two paths at the top, and replace the sample content.

Dashboard

A full product page built from the blocks: hero with a flow diagram, customer names, a module catalogue, three feature rows with live demos, a pricing claim, a closing band and a dark footer. Every section is documented on the Blocks page, with its code ready to paste.

Landing page

Use a template

  1. Copy the file from templates/ into your project.
  2. Change the two paths in the head to where your dist files live.
  3. Set the form action and field name values to match your server.
  4. Replace the sample text and data. In PHP, loop over your rows inside the table body.
