Get started

Install the kit

Two files give you everything: one stylesheet and one script. There is no build step for HTML and PHP projects.

Quick start

Build the kit once, copy the dist folder into your project, then link the two files.

1. Build

    cd xsenze-ui-kit
    npm install
    npm run build

2. Copy

Copy dist/ to your project, for example to assets/xsenze/. Keep the folder together: the stylesheet loads its fonts from fonts/ next to it.

3. Link

That is the whole setup. Components start by themselves when the page loads.

4. The heading font

Headings, buttons and numbers use Satoshi. Its free licence lets you use it on any website, but not pass the font file on, so the npm package does not include it. Download Satoshi from Fontshare, then put Satoshi-Variable.woff2 in the fonts/ folder next to xsenze-satoshi.css.

Without the file, or without xsenze-satoshi.css, headings use Space Grotesk. Nothing breaks.

PHP projects

Put the two tags in your shared header file and add a version to the address, so browsers fetch the new files after you update the kit.

Format money and dates on the server the same way the kit does in the browser:

    <?php
    // ₹12,34,567 with lakh and crore grouping. Needs the intl extension.
    $fmt = new NumberFormatter('en_IN', NumberFormatter::DECIMAL);
    echo '₹' . $fmt->format(1234567);

    // 15 Nov 2026
    echo date('j M Y', strtotime('2026-11-15'));

CDN

The dist folder is the CDN build. Upload it to any static host or your own CDN and link to it with the version in the path, so each release has a permanent address.

Replace cdn.example.com with your host. Serve the files with CORS enabled (Access-Control-Allow-Origin: *) so the fonts load from other domains.

Not on npm yet
The package is named @sfj/ui-kit and is ready to publish, but publishing is part of Phase 2. Until then, use the dist folder.

Bundlers and frameworks

In a project with a bundler, install the kit from its folder and import it.

    npm install ../xsenze-ui-kit
  
    import '@sfj/ui-kit/css';
    import Xsenze from '@sfj/ui-kit';

    // After you add markup to the page later (a route change, an AJAX response):
    Xsenze.init(document.querySelector('#new-content'));

Tokens only

To keep your own components but share the kit's values, load only the variables.

To change a value, edit tokens/tokens.json and run npm run build. Then run npm run check to confirm the colours still meet AA contrast.

Figma library

The Figma library uses the same token names as the code. To create or refresh its variables:

  1. Open the Xsenze UI Kit library file in Figma.
  2. Run a variables import plugin that reads the Design Tokens format.
  3. Choose dist/tokens/tokens.dtcg.json. The core group becomes the primitives collection. The theme group becomes one collection with a Light mode and a Dark mode.
  4. Publish the library so other files receive the update.

Name component properties in Figma after the class modifiers, for example a Button with variant (primary, default, solid, soft, ghost, link, danger) and size (sm, md, lg). Then a design reads the same as its markup.

Themes

Light is the default. Set data-theme on the html element to choose a theme, or on any element to theme just that part of the page.

Markup or callResult
data-theme="light"Light theme.
data-theme="dark"Dark theme.
data-theme="auto"Follows the device setting when the page loads.
data-xz-theme-togglePut this on a button. A click switches the theme and remembers the choice in the browser.
Xsenze.theme.set('dark')Sets and remembers a theme. Also get() and toggle().

Round the corners

Corners are 4px. Two tokens control the corner radius of every component, so a product that needs a square or a softer look can change it in one place.

    :root {
      --xz-radius-control: var(--xz-radius-lg);  /* buttons, inputs, badges */
      --xz-radius-surface: 12px;  /* cards, modals */
    }

Script reference

Most behaviour needs only a data attribute. The script API covers the rest.

CallWhat it does
Xsenze.init(root)Starts components inside root. Call it after adding markup to the page.
Xsenze.toast(options)Shows a toast. Options: title, message, variant, duration, action.
Xsenze.modal.open(target)Opens a modal or drawer. target is a selector or an element. Also close(target).
Xsenze.validate(form)Checks a form, shows messages and returns true when it is valid.
Xsenze.icon(name, options)Returns the SVG markup for an icon. Options: size, label.
Xsenze.format.inr(value)Formats money and dates. See Indian formats.
Xsenze.theme.set(name)Switches the theme.

Browser support

The kit supports the last two versions of Chrome, Edge, Firefox and Safari, on desktop and mobile. It uses the native dialog element and the :has() selector, which need Chrome 105, Firefox 121 or Safari 15.4 and later.
