Forms

Advanced form controls

Pickers, uploads and richer inputs. Each one keeps a normal form field up to date, so a plain HTML or PHP form post receives the value without any extra script.

Date picker

People can type a date as DD/MM/YYYY or pick it from the calendar. The hidden field holds the value as YYYY-MM-DD, which is what your server should read.

Between 1 Nov 2026 and 31 Mar 2027.

Date range

Add data-xz-datepicker="range" and a second hidden field. The first click sets the start and the second sets the end.

AttributeWhat it does
data-xz-datepickerTurns the wrapper into a date picker. Use the value range for two dates.
data-xz-min, data-xz-maxEarliest and latest allowed date, as YYYY-MM-DD. Days outside are struck through and cannot be chosen.
data-xz-week-start="0"Starts the week on Sunday. The default is Monday.
xz:date eventFires on the wrapper when the value changes. event.detail has start and end.

Keyboard: Down arrow in the field opens the calendar. Arrow keys move by day and week, Page Up and Page Down by month, Home and End to the ends of the week, Enter chooses, Escape closes.

Time picker

A list of times at a fixed step. People can also type a time such as 2:30 pm, 230pm or 14:30. The hidden field holds 24-hour HH:MM.

AttributeWhat it does
data-xz-stepMinutes between the times in the list. The default is 30.
data-xz-min, data-xz-maxFirst and last time, as HH:MM in 24-hour form.
xz:time eventFires on the wrapper with event.detail.value.

File upload

People can drag files in or browse for them. Files that are the wrong type or too large are listed with the reason and are not sent. The real file input always matches the list.

ID proof
    AttributeWhat it does
    accept on the inputAllowed types, such as .pdf,image/*. Also checked for dropped files.
    multiple on the inputAllows more than one file. Without it, a new file replaces the old one.
    data-xz-max-sizeLargest allowed file in MB.
    data-xz-max-filesMost files allowed.
    xz:files eventFires with event.detail.files and event.detail.rejected.

    Check the type and size again on the server. Browser checks help people, but they can be bypassed.

    One-time code

    One box per digit. Typing moves to the next box, Backspace moves back, and a pasted or auto-filled code fills every box. The hidden field holds the full code.

    Enter the 6-digit code sent to +91 98765 43210

    Did not get it? Send the code again

    The wrapper fires xz:otp-complete with event.detail.value when every box is filled, so you can submit the form at once.

    Tag input

    Type a word and press Enter or comma to add it. Backspace in an empty field removes the last tag. The hidden field holds the tags separated by commas.

    Up to 6. Press Enter after each one.

    Rich text editor

    A small editor for descriptions and notes: bold, italic, underline, a heading, lists and links. The hidden textarea holds clean HTML with only those tags. Pasted text comes in as plain text.
